# Doc2Audio

## Purpose
Doc2Audio converts documents into natural audio.

## Current Status
MVP deployed on Netlify.

## Tech Stack
- React
- GitHub
- Netlify

## Features Implemented
- Upload document
- Convert document to audio
- Download audio file
- Installable PWA

## Future Features
- User accounts
- Google login
- Multiple voices
- Audio library
- Stripe subscriptions
- Mobile apps

## Business Model

Free Plan
- Limited conversions

Pro Plan
- More conversions
- Premium voices

Premium Plan
- Unlimited use

## Design Rules
- Keep UI simple
- Mobile first
- Fast conversion
- Production ready code only

## Current Goal
Prepare Doc2Audio for public launch and revenue generation.
